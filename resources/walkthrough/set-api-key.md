## Set your Command Code API key

A Command Code API key is required to use this provider. Get one from
[Command Code Studio](https://commandcode.ai/studio/) and paste it in here.

1. [Create or copy an API key](command:commandcode-copilot.getApiKey) from Command Code Studio.
2. [Set the API key](command:commandcode-copilot.setApiKey) — it is stored in your OS keychain, never in plain text.
3. Run **Command Code: Refresh Models** to load the live model catalog into the picker.
