## Pick a Command Code model

After saving your API key, open Copilot Chat and click the model picker. Every
Command Code model that ships in the Provider catalog is available — Claude,
GPT, Gemini, DeepSeek, Kimi, Qwen, Grok, GLM, and more.

Each model exposes a **Thinking effort** dropdown directly in the picker. Pick
`Off` for fastest responses, `Standard` for everyday work, or `Deep` for the
hardest problems.

If a model is missing, open [VS Code's Language Models manager](command:workbench.action.chat.manage)
and enable the Command Code entries you want to see.
